# Dashboard — the ops room

Three columns, no reflow. Left is the agent terminal feed (monospace,
color-coded by message type). Center is the site map with severity pins
and the drone replay scrubber pinned to the bottom. Right is the event
list grouped by severity with filter pills.

Clicking any event row links to `../incident/index.html`.
Scrub: drag the handle or click the track to move the drone marker.
Filter: click a severity pill to hide/show its group.
